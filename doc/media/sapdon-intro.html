Minecraft Bedrock · Addon Framework

SAPDON

用 TypeScript 声明物品、方块、实体和界面，
构建期生成 JSON 包，直接进游戏。

build-time: @sapdon/core runtime: @sapdon/runtime no hand-written JSON
01 / Declare

像写普通代码一样
声明一个物品

类型提示补全字段，参数写错在编译期就报。最后一行 registry.submit() 提交整批注册。

main.ts
import { ItemAPI, ItemCategory,
         ItemComponent, registry } from '@sapdon/core'
 
const wand = ItemAPI.createItem(
  'demo:magic_wand',
  ItemCategory.Items,
  'magic_wand'
)
 
wand.addComponent(
  ItemComponent.setDisplayName('魔杖'),
  ItemComponent.setInteractButton('施法')
)
 
registry.submit()  // 提交
BUILD
02 / Build

行为包放逻辑与数据，资源包放贴图与文本。改完代码重新构建，产物同步进游戏开发包目录。
