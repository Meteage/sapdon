# fluid_pipe — 流体管道 Addon

Minecraft 基岩版流体管道系统（sapdon 框架 + `@minecraft/server` 2.6.0，TypeScript）。
流体在管道中从**势高**流向**势低**；**向上爬升每格耗势 1**；泵造势（顶面输出/底面输入）；水只由泵提供（泵入水口底面接触水后吐水）；空气端子为势的汇（-1）。

> 技术实现见 `DESIGN.md`；本手册聚焦**怎么用**。

---

## 1. 方块总览

| 方块 | 用途 |
|---|---|
| `fluid_pipe:fluid_pipe`（流体管道） | 玻璃管道，内含水柱（32 帧翻书动画）。放置自动与相邻管道/设备连接（全 6 面） |
| `fluid_pipe:pump`（泵） | 可 6 面旋转（放置时按玩家朝向）：自身参考系**顶面=输出口（高压端）、底面=输入口（低压端）**（随旋转映射到世界面）。顶/底为 digitCircuit 风格 input/output 符号（白标于灰色金属噪声底）。右键或扳手启动/停止 |
| `fluid_pipe:tank`（储液罐） | **仅顶面可连管道**；液位 0~32 格；纯吸收：未满=吸入（势 -1），满=停止，不向外排水 |
| `fluid_pipe:valve`（单方向阀门） | 可 6 面旋转（放置时按玩家朝向，自身参考系）：**西面=输入、东面=输出**（随旋转映射）；顶面箭头 →=开、↑=关（与三通统一箭头）；**扳手只切换顶面箭头（开/关），方块朝向不动**；开时单向透传（西→东） |
| `fluid_pipe:valve3`（三通阀） | 可 6 面旋转（放置时按玩家朝向，自身参考系）：**西面=输入**，北/东/南=可选输出；扳手**顺时针**循环（东→南→西→北）；**箭头指向西（输入）=全关**；顶面单箭头指示当前方向。**出水口喷水**：输入面管道有水且开通面没有管道/设备连接时，出水口喷水粒子 |
| `fluid_pipe:wrench`（管道扳手） | 点单阀旋转 90°（开/关）、点三通顺时针切换输出、点泵开关、点管道查看段诊断、点罐查看液位 |

## 2. 势模型（一句话版）

- **源**：仅泵输出口（运行）→ **+4**（泵入水口底面接触水、或输入侧管道有水才吐）；管道不吸水、水块不供水、罐不能当源
- **汇**：对空气 → 势 **-1**（流失）；罐 → **-1**（未满吸入、满停吸）；泵输入口 → **-4**（强吸）
- **高度**：向上爬升 1 格势 **-1**；向下/水平不减
- 多源传播：系统计算流体到达目标所需的**最大势**；流动判定 = 可用势 > 目标所需势
- 泵为**并联造势**：输出口独立抬势 +4（扬程 5 格），输入口强吸 -4；输入侧有水才吐（不凭空造水）；罐液位 0~32 格，未满自动吸、满停吸

## 3. 快速上手

1. **放管道**：直接放置，自动连接相邻管道/设备。管道不会自己吸水——水只由泵提供。
2. **接水源**：把泵**底面（入水口）贴着水**（泵底相邻水块，或泵自身被水浸没）→ 泵直接抽水吐给输出段。侧/顶面接触水不算——入水口断开即停水。
3. **放泵**：把泵放在管道段之间——**顶面朝送水方向的上游侧**（水从底面被吸入、顶面吐出）；右键/扳手启动。泵能克服约 4 格高度。
4. **放罐**：管道末端从**罐顶面**接入；罐未满时吸入（势 -1 强汇），满 32 格停止（纯吸收，不排水）。
5. **放单方向阀门**：装在管道中间，**自身参考系西面接来水、东面接去水**（放置时朝向决定映射到世界的哪个面）；顶面箭头 →=开；扳手切换 →/↑（开/关），方块朝向不变。
6. **放三通阀**：**西面接输入管道**（自身参考系，随放置朝向映射），扳手顺时针循环切换输出方向（东→南→西→北，指向西=全关），顶面箭头指示。**输入面有水 + 开通面没接管道/设备时，出水口会喷水粒子**。
7. **调试**：扳手点管道看段前沿/高势端点；`fluid_pipe:fluid_log on` 开启运行期日志（写 ContentLog）。

## 7. 已知限制（v2）

- **有效管道**：段必须同时有**输入端点**（泵输出/阀门输出）与**输出端点**（罐/阀门输入/泵输入）才渲染水；孤立管道、仅空气端管道不显示水。**水流通路径**：只渲染连接输入→输出端点的管道，**死胡同支路不显示水**（如泵→管→两条闭合支路+一条阀门支路，只有阀门支路流水）。**泵泡水**（泵**底面**接触水/被水浸没，侧顶面不算）可直接吐水给输出段。
- 势场驱动渲染：水只渲染在**势已到达**（`pot > -1`）的管道；水前沿每 20 tick 渐进逼近势覆盖范围（+FRONT_SPEED/20tick）。**水为存量**：断源/势消失/关阀后水保留不退（不再流动），重新接源恢复流动；拆除管道方块即清空该处。
- **级联填充**：多级阀门串联时，水从源到目标**一级一级推进**——上一级管段充满后，下一级才进水（阀门喂水段受此闸门约束；泵直供段不受限）。
- **罐吸水按可见水**：罐只在**水前沿到达罐端管道**后才开始吸水（级联时罐随水流到达才加水）；罐纯吸收——满 32 格后停止吸入，不向外排水。
- **阀门可直接首尾相连**：阀门之间无需管道（`A—阀—阀—C` 也能通水，链穿越补端点）；关阀 = 墙，链断。
- 罐渲染为 0/1 两档（液位 0~32 存内存，多档渲染可后扩展）。
- 势传播场每 20 tick 全量重算（局部优化后做）。
