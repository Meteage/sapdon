# fluid_pipe — 流体管道 Addon

Minecraft 基岩版流体管道系统（sapdon 框架 + `@minecraft/server` 2.6.0，TypeScript）。
流体在管道中从**势高**流向**势低**；**向上爬升每格耗势 1**；泵造势（顶面输出/底面输入）；管道浸润水源处势=1；空气端子为势的汇（-1）。

> 技术实现见 `DESIGN.md`；本手册聚焦**怎么用**。

---

## 1. 方块总览

| 方块 | 用途 |
|---|---|
| `fluid_pipe:fluid_pipe`（流体管道） | 玻璃管道，内含水柱（32 帧翻书动画）。放置自动与相邻管道/设备连接（全 6 面） |
| `fluid_pipe:pump`（泵） | 可旋转：**顶面=输出口（高压端）、底面=输入口（低压端）**。顶/底为 digitCircuit 风格 input/output 符号（白标于灰色金属噪声底）。右键或扳手启动/停止 |
| `fluid_pipe:tank`（储液罐） | **仅顶面可连管道**；液位 0~32 格；未满=吸入（势 -1），满=停止；液位>0 时作为弱源可排水 |
| `fluid_pipe:valve`（单方向阀门） | 可旋转（放置时玩家可转，**西/东为自身参考系**）：**西面=输入、东面=输出**；顶面箭头 →=开、↑=关（与三通统一箭头）；**扳手只切换顶面箭头（开/关），方块朝向不动**；开时单向透传（西→东） |
| `fluid_pipe:valve3`（三通阀） | 可旋转（自身参考系）：**西面=输入**，北/东/南=可选输出；扳手**顺时针**循环（东→南→西→北）；**箭头指向西（输入）=全关**；顶面单箭头指示当前方向 |
| `fluid_pipe:wrench`（管道扳手） | 点单阀旋转 90°（开/关）、点三通顺时针切换输出、点泵开关、点管道查看段诊断、点罐查看液位 |

## 2. 势模型（一句话版）

- **源**：管道贴着水（浸润）→ 势 **1**；泵输出口（运行）→ **+4**；满罐 → **0**（重力排水源）
- **汇**：对空气 → 势 **-1**（流失）；未满罐 → **-1**（吸入）；泵输入口 → **-4**（强吸）
- **高度**：向上爬升 1 格势 **-1**；向下/水平不减
- 多源传播：系统计算流体到达目标所需的**最大势**；流动判定 = 可用势 > 目标所需势
- 泵为**并联造势**：输出口独立抬势 +4（扬程 5 格），输入口强吸 -4；输入侧有水才吐（不凭空造水）；罐液位 0~32 格，满自动重力排、低于满自动吸

## 3. 快速上手

1. **放管道**：直接放置，自动连接相邻管道/设备。
2. **接水源**：管道贴着水（或浸入水中）即可从该处吸水（势=1）。
3. **放泵**：把泵放在管道段之间——**顶面朝送水方向的上游侧**（水从底面被吸入、顶面吐出）；右键/扳手启动。泵能克服约 4 格高度。
4. **放罐**：管道末端从**罐顶面**接入；罐未满时吸入（势 -1 强汇），满 32 格停止。
5. **放单方向阀门**：装在管道中间，**自身参考系西面接来水、东面接去水**（放置时可旋转调向）；顶面箭头 →=开；扳手切换 →/↑（开/关），方块朝向不变。
6. **放三通阀**：**西面接输入管道**（自身参考系），扳手顺时针循环切换输出方向（东→南→西→北，指向西=全关），顶面箭头指示。
7. **调试**：扳手点管道看段前沿/高势端点；`fluid_pipe:fluid_log on` 开启运行期日志（写 ContentLog）。

## 7. 已知限制（v2）

- **有效管道**：段必须同时有**输入端点**（泵输出/阀门输出）与**输出端点**（罐/阀门输入/泵输入）才渲染水；孤立管道、仅泡水管（泡水不算输入）不显示水。**水流通路径**：只渲染连接输入→输出端点的管道，**死胡同支路不显示水**（如泵→管→两条闭合支路+一条阀门支路，只有阀门支路流水）。**泵泡水**（泵被水浸没）可直接吐水给输出段。
- 势场驱动渲染：水只渲染在**势已到达**（`pot > -1`）的管道；水前沿每 20 tick 渐进逼近势覆盖范围（填充/退水都是 +FRONT_SPEED/20tick）。水源消失或断段后，水会渐渐退干。
- 罐渲染为 0/1 两档（液位 0~32 存内存，多档渲染可后扩展）。
- 势传播场每 20 tick 全量重算（局部优化后做）。
