# power_grid — 电力电网 Addon

Minecraft 基岩版电力系统（sapdon 框架 + `@minecraft/server` 2.6.0，TypeScript）。
`power_grid` 是 **逻辑层 L / 渲染层 R 分离** 架构的第三个例子（前两例：`digitCircuit` 数电、`fluid_pipe` 流体）。
电力系统同样内含 **连接(C₁)/源(S)/功能(F)/消费(Cc)/储量(R)** 五元组，范式见仓库 `doc/dev/lr-paradigm.md`。

> 技术实现见 `DESIGN.md`；本手册聚焦**怎么用**。

---

## 1. 方块总览

| 方块 | 用途 |
|---|---|
| `power_grid:wire`（电线） | 连通单元，6 面正交自动连通；带电则发橙光贴图 |
| `power_grid:coal_generator`（燃煤发电机） | 手持**煤炭右键**喂煤；有煤即发电 **40/s**（每块煤燃 10s，产出周期）；燃烧中贴图切换 |
| `power_grid:solar`（太阳能板） | 白天按日照发电 **10/s**，夜晚 0 |
| `power_grid:electric_furnace`（电力熔炉） | 手持**可熔炼物品右键**放入原料；通电才熔炼（10s/个），断电停熔；产物以物品实体喷出 |
| `power_grid:battery`（电池） | 储电，容量 1000；发电富余→充电、不足→放电补缺，`power_grid:level` 显电量 |
| `power_grid:relay`（继电器） | **功能块/可控桥**：万用表点按通/断；导通=合并两侧电网，关断=分隔 |
| `power_grid:multimeter`（万用表） | 点电线看段、点继电器切开关、点设备看状态 |

## 2. 电网模型（一句话版）

- **并网**：共享同一设备的线段并成一个 **Grid**（电网）。发电机/电池/电炉无条件连通两侧；**继电器仅导通时**连通（关断=分隔）。
- **结算**（每 20t≈1s）：`供 = Σ发电机 + Σ太阳能 + Σ电池放电(受速率/余量)`，`需 = Σ电炉耗电(30/s)`。
  - 供 ≥ 需 → 全 Grid 通电，电池充电 `min(60, 盈余)`
  - 供 < 需 → 电池先补缺；仍缺 → 断电（熔炉停、线灭）
- 燃煤在发电时才消耗；太阳能不耗燃料。

## 3. 快速上手

1. **布线**：放电线，正交相邻自动连通（同一段）。
2. **接源**：放燃煤发电机，手持煤炭右键它喂煤（存煤计数，发电中消耗）；或白天放太阳能板。
3. **储能**：放电池接入电网，富余时自动充电，不足时自动放电补缺。
4. **用电**：放电力熔炉，手持铁矿石等右键放入原料；通电即熔炼，10s 后产出锭。
5. **分线路**：放继电器在两组电线之间，通电即合并两侧；用万用表点它可通/断（可作闸刀）。
6. **调试**：万用表点电线/设备看状态；`power_grid:power_log on` 开运行期日志（写 ContentLog）。

## 6. 构建与测试

```
npm run build              # 输出到 dev/ 并同步游戏开发包
node --test test/power.test.mjs   # L 层核心逻辑（10 断言）
```

> `test/power.test.mjs` 是 `scripts/core/`（graph/settle，门面 `powerCore.ts`）的 Node 镜像副本：**改核心逻辑必须同步测试副本**。
> 注意：`npm i` 会剪掉手工写入的 `node_modules/@sapdon/*`，装完依赖后需重新执行 `sapdon lib`。

## 7. 已知限制（v1）

- **贴图为程序化原创**：由 `tools/power_textures.ps1` 绘制（噪声机身 + 形状特征，16×16 MC 风格），每设备独立配色。若要更精致的风格化重绘，按 `AGENTS.md` 贴图铁律先过 exam 再改。
- 电线连通为**正交相邻自动连通**（同流体管道），无逐面手臂控制，因此不能做"单线弯折"。若需方向控制可后续叠加 `pipe_connect:*` 手臂。
- 电网结算为**网格级全局**（全有/全无通电），未做线路损耗/压降；需"势/距离消耗"模型可参考 fluid_pipe。
- 电炉原料为单格记忆槽（每次 1 个物品），不支持堆叠批次熔炼。
- 夜间先耗尽电池仍断电；太阳能无储能在夜晚即断电（符合直觉）。
